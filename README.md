## Software Description

An AI-powered academic planning tool that syncs with Canvas to automatically import assignments, prioritize tasks, and schedule work into your available time. It keeps users motivated with streak tracking while continuously adjusting plans to ensure deadlines are met efficiently.

## Architecture

-React
-Expo
-Vite

## Software Features

- Streak
- A.I Scans, Suggested Plan/ Priority Queue
- Auto Scheduled Assignments
- Link to Canvas
